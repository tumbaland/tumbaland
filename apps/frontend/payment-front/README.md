# payment-front

Frontend for managing plans, subscriptions, and payment history.

## Pages
- PlansPage: list available plans & start subscription
- SubscriptionPage: view/cancel current subscription
- PaymentsHistoryPage: list one-time and subscription payments

## Env Vars (.env)
VITE_PAYMENT_API_URL
VITE_AUTH_SERVICE_URL
VITE_AUTH_FRONT_URL

## Dev
npm install
npm run dev

## Build
npm run build
