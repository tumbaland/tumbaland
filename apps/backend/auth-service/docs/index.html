💡 Usage Examples

Validate a Google ID Token:

# Validate token using cURL curl -X POST http://localhost:3000/auth/validate \ -H "Content-Type: application/json" \ -d '{"idToken": "your-google-id-token"}' # Response includes user information { "success": true, "user": { "email": "user@example.com", "name": "John Doe" } }

🔧 Configuration

The service requires Google Cloud Storage authentication. See the setup documentation for configuration details:

  • Service Account: Set up with Storage Object Admin role
  • Bucket Access: Uniform bucket-level access enabled
  • Environment: Configure project ID, bucket name, and credentials
