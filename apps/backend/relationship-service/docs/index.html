📋 Available Endpoints

Here's a quick overview of all available API endpoints:

GET /api/activities Get all activities with filtering
POST /api/activities Create a new activity
GET /api/activities/{id} Get activity by ID
PUT /api/activities/{id} Update activity
DELETE /api/activities/{id} Delete activity
GET /api/activities/recent Get recent activities
GET /api/activities/date-range Get activities by date range
GET /api/activities/types Get activity types
GET /api/activities/stats Get activity statistics
