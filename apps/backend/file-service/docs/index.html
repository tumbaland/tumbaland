📋 Available Endpoints

Here's a quick overview of all available API endpoints:

POST /api/upload Upload a file and get unique ID
POST /api/upload-url Get signed URL for direct upload
GET /api/signed-url/{fileId} Get signed URL for file access
GET /api/download/{fileId} Download file directly
GET /api/{fileId} Get file metadata
DELETE /api/{fileId} Delete file by ID
GET /api/ List all files with filtering

💡 Usage Examples

Upload a file:

# Upload file using cURL curl -X POST http://localhost:5002/api/upload \ -F "file=@/path/to/your/image.jpg" # Response includes unique file ID { "success": true, "data": { "id": "21d197c3-7e7a-458d-a7d6-b1a271f657af.jpg", "name": "Big party.jpg", "size": 75430, "url": "https://storage.googleapis.com/..." } }

Delete a file by ID:

# Delete using the file ID from upload response curl -X DELETE http://localhost:5002/api/21d197c3-7e7a-458d-a7d6-b1a271f657af.jpg # Response confirms deletion { "success": true, "data": { "message": "File deleted successfully", "fileId": "21d197c3-7e7a-458d-a7d6-b1a271f657af.jpg" } }

Get secure access URL:

# Get signed URL that expires in 2 hours curl http://localhost:5002/api/signed-url/21d197c3-7e7a-458d-a7d6-b1a271f657af.jpg?expires=120

🔧 Configuration

The service requires Google Cloud Storage authentication. See the setup documentation for configuration details:

  • Service Account: Set up with Storage Object Admin role
  • Bucket Access: Uniform bucket-level access enabled
  • Environment: Configure project ID, bucket name, and credentials
