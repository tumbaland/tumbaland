🤖 Vision Service API

Backend API for managing machine learning datasets, training configurations, and training epochs

Computer Vision Model Training Management System

📋 Overview

The Vision Service provides a complete RESTful API for managing machine learning training data for computer vision models. It supports flexible, dynamic schemas that can evolve with your needs.

📊 Dataset Management

Store comprehensive dataset analysis including class distributions, camera statistics, and LiDAR information.

⚙️ Training Configuration

Track complete training configurations with hyperparameters, model settings, and status tracking.

📈 Epoch Tracking

Monitor training progress with detailed metrics per epoch including IoU, precision, recall, and loss values.

🔄 Dynamic Schema

Flexible data structures that adapt to your evolving requirements without schema migrations.

Data Flow

Dataset → Training Configuration → Multiple Epochs

Quick Start

# Health check
curl http://localhost:4010/health

# List datasets
curl http://localhost:4010/api/datasets

# Create a training
curl -X POST http://localhost:4010/api/trainings \
  -H "Content-Type: application/json" \
  -d '{"name":"My Training","configuration":{}}'

🚀 Features

  • RESTful API - Clean, intuitive REST endpoints following industry standards
  • Pagination & Filtering - Built-in pagination, search, and filtering for all list endpoints
  • Flexible Schema - Dynamic data structures supporting evolving requirements
  • Batch Operations - Efficient batch creation for importing historical data
  • Multiple Identifiers - Support for both MongoDB IDs and UUIDs
  • Cascading Deletes - Automatic cleanup of related data
  • Comprehensive Monitoring - Health checks, Prometheus metrics, and distributed tracing
  • TypeScript - Full type safety and excellent developer experience

🛠️ Technology Stack

  • Runtime: Node.js 20 with TypeScript
  • Framework: Express.js 5
  • Database: MongoDB with Mongoose ODM
  • Monitoring: Prometheus metrics, distributed tracing, structured logging
  • Containerization: Docker & Docker Compose

📊 Datasets

GET /api/datasets List all datasets
GET /api/datasets/:id Get dataset by ID
GET /api/datasets/uuid/:uuid Get dataset by UUID
POST /api/datasets Create dataset
PUT /api/datasets/:id Update dataset
DELETE /api/datasets/:id Delete dataset

⚙️ Trainings

GET /api/trainings List all trainings
GET /api/trainings/:id Get training by ID
GET /api/trainings/uuid/:uuid Get training by UUID
GET /api/trainings/:id/epochs Get training with epochs
POST /api/trainings Create training
PUT /api/trainings/:id Update training
DELETE /api/trainings/:id Delete training + epochs

📈 Epochs

GET /api/epochs/training/:trainingId Get epochs by training
GET /api/epochs/:id Get epoch by ID
GET /api/epochs/uuid/:uuid Get epoch by UUID
POST /api/epochs Create epoch
POST /api/epochs/batch Create multiple epochs
PUT /api/epochs/:id Update epoch
DELETE /api/epochs/:id Delete epoch

🏥 System

GET /health Health check

🐍 Python Integration Example

import requests
from datetime import datetime

class VisionServiceClient:
    def __init__(self, api_url="http://localhost:4010/api"):
        self.api_url = api_url
        self.training_id = None
        self.training_uuid = None
    
    def create_training(self, name, dataset_id, config):
        response = requests.post(
            f"{self.api_url}/trainings",
            json={
                "name": name,
                "datasetId": dataset_id,
                "configuration": config,
                "status": "running"
            }
        )
        result = response.json()
        if result["success"]:
            self.training_id = result["data"]["_id"]
            self.training_uuid = result["data"]["uuid"]
        return result
    
    def log_epoch(self, epoch, results, learning_rate=None):
        response = requests.post(
            f"{self.api_url}/epochs",
            json={
                "trainingId": self.training_id,
                "training_uuid": self.training_uuid,
                "epoch": epoch,
                "results": results,
                "learning_rate": learning_rate
            }
        )
        return response.json()

# Usage
client = VisionServiceClient()
client.create_training("My Training", "dataset-id", {...})

for epoch in range(100):
    results = {...}  # Your training results
    client.log_epoch(epoch, results)
